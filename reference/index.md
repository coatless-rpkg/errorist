# Package index

### Autorun functions on Package Load and Unload

Automatically enable or disable searching of errors and warning
messages.

- [`enable_errorist()`](https://r-pkg.thecoatlessprofessor.com/errorist/reference/errorist_init.md)
  [`disable_errorist()`](https://r-pkg.thecoatlessprofessor.com/errorist/reference/errorist_init.md)
  : Enable or Disable Errorist's Automatic Search

### Behavior Shims

Individually turn on or off searching errors and warning messages.

- [`enable_warning_shim()`](https://r-pkg.thecoatlessprofessor.com/errorist/reference/shims.md)
  [`disable_warning_shim()`](https://r-pkg.thecoatlessprofessor.com/errorist/reference/shims.md)
  [`enable_error_shim()`](https://r-pkg.thecoatlessprofessor.com/errorist/reference/shims.md)
  [`disable_error_shim()`](https://r-pkg.thecoatlessprofessor.com/errorist/reference/shims.md)
  : Enable and Disable Warning or Error Capture
